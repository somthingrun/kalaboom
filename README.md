# کالابوم – شروع پروژه Flutter

این بسته یک اسکلت اولیه و قابل توسعه برای بازارچه فارسی است.

## پیش‌نیازها
- Flutter SDK پایدار
- Android Studio یا VS Code
- Android SDK و ابزارهای ساخت

## اجرا
1. فایل ZIP را استخراج کنید.
2. در پوشه پروژه اجرا کنید:
   flutter pub get
   flutter run

## خروجی APK
flutter build apk --release

فایل خروجی معمولاً در مسیر زیر ساخته می‌شود:
build/app/outputs/flutter-apk/app-release.apk

## وضعیت فعلی
- رابط فارسی و راست‌چین
- صفحه خانه و دسته‌بندی‌ها
- صفحات جست‌وجو، ثبت آگهی، علاقه‌مندی و حساب کاربری
- صفحه ورود با شماره موبایل و فرم کد تأیید نمایشی

## مواردی که هنوز باید پیاده‌سازی شوند
- اتصال واقعی Supabase و طراحی جداول
- ارسال و اعتبارسنجی واقعی OTP از طریق ارائه‌دهنده پیامک مجاز
- ذخیره‌سازی و آپلود تصاویر
- جست‌وجوی واقعی، چت و اعلان‌ها
- پنل مدیریت و گزارش تخلف
- قوانین حریم خصوصی، شرایط استفاده و تست امنیتی

نکته: صفحه ورود فعلاً نمایشی است و پیامک واقعی ارسال نمی‌کند. برای فعال‌سازی آن باید پروژه Supabase، تنظیمات احراز هویت و سرویس پیامکی مناسب بازار ایران تهیه و پیکربندی شود.
